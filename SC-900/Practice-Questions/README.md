# SC-900 — Practice Questions

## 🎯 Interactive quiz (Domain 1)

**[Open the quiz →](https://REPLACE-USERNAME.github.io/Microsoft-SC-Certifications-Trainings/SC-900/Practice-Questions/)**

`index.html` is a single self-contained page — no build step, no dependencies, no tracking. You can also just download it and double-click it.

What it does:

- **12 exam-style questions.** Choose an answer and you immediately see why it's right **and why each of the other three is wrong**.
- **Options are shuffled on every attempt,** so retaking it tests the concept rather than the position you memorized.
- **Lab 1 — shared responsibility model.** Fill the table from memory; it grades every cell and gives corrections.
- **Lab 2 — Zero Trust pillar map.** Six pillars; it flags the ones you left blank and your notes persist in the browser.

Scoring guide: 11–12 means the domain is done. 9–10, reread the misses. Below 9, the gap is almost always the shared responsibility model or hashing vs encryption.
