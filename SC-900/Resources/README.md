## Lab environment

An Azure free account plus product trials. **The Microsoft 365 Developer Program no longer accepts personal accounts** — it requires a qualifying subscription or partner/support membership, so guides that send you there are out of date. Setup instructions are in [`../Study-Guides/00-sc900-series-index.md`](../Study-Guides/00-sc900-series-index.md).

## Suggested plan (2–3 weeks, 1 hour/day)

| Days | Focus |
|---|---|
| 1 | Set up the lab, read the series index |
| 2–3 | Domain 1 — concepts, then the interactive quiz |
| 4–7 | Domain 2 — Entra, plus both Entra labs |
| 8–12 | Domain 3 — security solutions (the biggest domain) |
| 13–15 | Domain 4 — Purview and compliance |
| 16–17 | Mock exam + official practice assessment |
| 18 | Review only your weak domain. No new material. |

## What to avoid

Sites selling "real exam questions" or "actual dumps". They violate the exam agreement, can get your certification revoked, and teach you nothing that survives an interview.
