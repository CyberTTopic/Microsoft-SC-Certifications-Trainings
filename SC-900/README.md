# SC-900 — Security, Compliance and Identity Fundamentals

**Status: ✅ Certified.** This folder holds the complete material I built while preparing, cleaned up and published.

The written series is also published on DEV: **[SC-900 in 2026 — The Complete Study Series](https://dev.to/cyberttopic/sc-900-in-2026-the-complete-study-series-4-domains-free-labs-60-practice-questions-3f6l)**.

SC-900 is the entry point to the Microsoft security track. It's conceptual — no configuration is required — but the vocabulary it teaches is the vocabulary every other SC exam is written in.

> Objectives were updated on **28 July 2026**. Always confirm the "Skills measured as of" date on the [official study guide](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/sc-900) before you study, and treat any material older than that date with suspicion.

## Suggested order

1. Read the [series index](Study-Guides/00-sc900-series-index.md) and set up the free lab environment.
2. Work through domains 1 → 4, one per session. Don't skip domain 1 because it's small; it's the vocabulary for the rest.
3. Do the labs as you go. A screenshot of a policy you built is worth more in an interview than the badge.
4. Take the [interactive quiz](Practice-Questions/) after each domain.
5. Finish with the [30-question mock exam](Study-Guides/05-mock-exam-glossary.md) and the official practice assessment.

Realistic timeline: **2 to 3 weeks** at an hour a day, less if you already work in IT.

## A note on the lab environment

Many older guides send you to the Microsoft 365 Developer Program for a free tenant. **That route no longer works with personal accounts** — it now requires a qualifying subscription or partner/support membership. The setup in the series index uses an Azure free account plus product trials instead. Verified as of the objectives update above.
