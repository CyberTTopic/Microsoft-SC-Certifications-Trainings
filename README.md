# Microsoft Security Certifications — Study Notes, Labs and Practice

Open study material for the Microsoft **SC** security certification track, written while preparing for the exams and kept updated as Microsoft changes the objectives.

Everything here is free to use. If it saves you an hour of study, it did its job.

## What's inside

Each exam folder follows the same structure:

```
SC-XXX/
├── README.md             Overview of the exam: domains, weights, resources
├── Study-Guides/         Domain-by-domain notes, written to be read
├── Labs/                 Hands-on exercises with expected results
├── Practice-Questions/   Questions with the reasoning behind every option
├── Exam-Tips/            Traps, memory hooks and exam-day strategy
└── Resources/            Official links and study plans
```

Plus three shared folders:

| Folder | Contents |
|---|---|
| `Images/` | Diagrams used across the notes (PNG, 1600×900) |
| `Templates/` | Reusable templates: study plans, lab checklists, note formats |
| `Documents/` | Longer documents, summaries and exports |

## How I write these

Three rules I hold myself to:

1. **Explain why the wrong answers are wrong.** Knowing the right answer is recognition; knowing why the other three fail is understanding. The exam tests the second one.
2. **Every claim is checkable.** Objectives, licence tiers and product names are linked to Microsoft Learn, with the date they were verified. Microsoft renames things constantly, so anything unverified gets flagged instead of asserted.
3. **Labs over lists.** If a concept can be clicked, there's a lab for it.

---

## ⚠️ On exam integrity

This repository contains **no real exam questions**, no braindumps and no NDA material. Everything here is original: written from the published objectives, Microsoft Learn documentation and hands-on practice.

Practice questions are written to test the same *concepts* the objectives describe. They are not, and are not intended to resemble, the questions you will see on exam day.

If you're studying from a site that promises "real exam questions", you're risking your certification and learning nothing. Use the official practice assessments instead — they're free.
