## Before you start

Check the "Skills measured as of" date on the official study guide. Microsoft updates these exams regularly, and material written before an update can be quietly wrong about product names and licence tiers.

Prerequisite in practice, not on paper: **[SC-900](../SC-900/)**. It isn't required to sit this exam, but the concepts and vocabulary carry over directly.
